# Zhongze Li — Academic Homepage

Personal academic website for Zhongze Li, PhD student in the Department of Electrical Engineering at Tsinghua University.

## Research focus

1. Multi-timescale modeling and robust stability for converter-dominated power systems.
2. Compositional and distributed stability analysis based on local device/network information.

## Deployment

This repository is published through GitHub Pages at https://lizzz766.github.io/.

The site intentionally uses plain static HTML with no external fonts, JavaScript frameworks, analytics, or CDN dependencies to reduce loading failures on constrained networks.
